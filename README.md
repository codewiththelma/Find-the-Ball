# Find The Red Ball

A simple Python game where the player tries to find the hidden red ball. The ball is shuffled among three options, and the player picks a number to guess its location. The game provides feedback and allows multiple attempts. It demonstrates basic use of functions, user input, and randomization in Python.

## Features
- Shuffling of three options to hide the red ball
- Player guesses the location of the red ball
- Provides feedback on whether the guess is correct or incorrect
- Allows multiple attempts to improve the guess

## Technologies Used
- **Python**: Core logic for the game including functions, randomization, and user input

## How to Play
1. Choose a number between 0 and 2.
2. The game will shuffle the red ball between three options.
3. Try to guess where the red ball is located.
4. Get feedback and try again if necessary.
